## STEP 4 — Route protection for Pro pages

Update `ProtectedRoute` to support Pro gating:

```typescript
// New: ProRoute component
export function ProRoute({ children }: { children: React.ReactNode }) {
  const { user, isLoading } = useAuth();
  
  if (isLoading) return <LoadingScreen />;
  if (!user) return <Redirect to="/login" />;
  if (!user.isPro) {
    // Don't redirect — render the upgrade page inline instead
    return <UpgradePage />;
  }
  return <>{children}</>;
}
```

`UpgradePage` is a full-page version of the upgrade modal — same content but rendered as a page within the AppShell, not a modal overlay. This way the sidebar is still visible, the user isn't ejected from the app, they just see a "upgrade to unlock" page.

## STEP 8 — Admin panel: grant Pro access

In `/admin/accounts` (Phase 4, to be built), add a "Grant Pro" toggle per user. For now, add a simple API route so you can manually grant Pro via a curl or a quick admin UI button.

Add to `server/routes.ts` (admin-only):
```
PATCH /api/admin/users/:id/pro
→ requireAuth + requireAdmin middleware
→ Body: { isPro: boolean }
→ Updates user.isPro and user.proGrantedAt
→ Returns updated user
```

`requireAdmin` middleware:
```typescript
async function requireAdmin(req: Request, res: Response, next: NextFunction) {
  if (!req.session.userId) return res.status(401).json({ message: "Unauthorized" });
  const user = await storage.getUserById(req.session.userId);
  if (!user?.isAdmin) return res.status(403).json({ message: "Forbidden" });
  next();
}
```
