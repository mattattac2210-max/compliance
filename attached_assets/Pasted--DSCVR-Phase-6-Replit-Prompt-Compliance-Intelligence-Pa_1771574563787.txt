```typescript

```

### A3 — New `recurring_filings` table

Tracks monthly/quarterly tax filings — a separate concept from document expiry. Documents expire once; filings recur forever.

```typescript
export const recurringFilings = pgTable("recurring_filings", {

/**
 * Generate concrete due dates from the schedule for the next N months from today.
 */
export function generateUpcomingFilings(monthsAhead = 3): Array<{
  filingType: string;
  labelKey: string;
  gateNumber: number;
  gateColor: string;
  dueDate: Date;
  isOverdue: boolean;
  daysUntil: number;
}> {
  const today = new Date();
  const cutoff = new Date(today);
  cutoff.setMonth(cutoff.getMonth() + monthsAhead);

  const results: ReturnType<typeof generateUpcomingFilings> = [];

  for (const item of FILING_SCHEDULE) {
    if (item.cadence === "monthly" && item.dueDayOfMonth) {
      // Generate one per month for the window
      const cursor = new Date(today.getFullYear(), today.getMonth(), item.dueDayOfMonth);
      if (cursor < today) cursor.setMonth(cursor.getMonth() + 1);
      while (cursor <= cutoff) {
        const daysUntil = Math.floor((cursor.getTime() - today.getTime()) / 86400000);
        results.push({
          filingType: item.filingType,
          labelKey: item.labelKey,
          gateNumber: item.gateNumber,
          gateColor: item.gateColor,
          dueDate: new Date(cursor),
          isOverdue: cursor < today,
          daysUntil,
        });
        cursor.setMonth(cursor.getMonth() + 1);
      }
    } else if (item.cadence === "quarterly" && item.dueMonths && item.dueDayInMonth) {
      for (const month of item.dueMonths) {
        const year = month <= today.getMonth() + 1 ? today.getFullYear() + 1 : today.getFullYear();
        const dueDate = new Date(year, month - 1, item.dueDayInMonth);
        if (dueDate >= today && dueDate <= cutoff) {
          results.push({
            filingType: item.filingType,
            labelKey: item.labelKey,
            gateNumber: item.gateNumber,
            gateColor: item.gateColor,
            dueDate,
            isOverdue: false,
            daysUntil: Math.floor((dueDate.getTime() - today.getTime()) / 86400000),
          });
        }
      }
    } else if (item.cadence === "annual" && item.dueMonths && item.dueDayInMonth) {
      for (const month of item.dueMonths) {
        let year = today.getFullYear();
        const dueDate = new Date(year, month - 1, item.dueDayInMonth);
        if (dueDate < today) dueDate.setFullYear(year + 1);
        if (dueDate <= cutoff) {
          results.push({
            filingType: item.filingType,
            labelKey: item.labelKey,
            gateNumber: item.gateNumber,
            gateColor: item.gateColor,
            dueDate,
            isOverdue: false,
            daysUntil: Math.floor((dueDate.getTime() - today.getTime()) / 86400000),
          });
        }
      }
    }
  }

  return results.sort((a, b) => a.dueDate.getTime() - b.dueDate.getTime());
}

## PART D — API ROUTES (`server/routes.ts`)

Add these routes. All require `requireAuth`.

### Banjar contributions

```
GET  /api/banjar?propertyId=:id
     → Return all banjar_contributions for property, ordered by contributionDate desc

POST /api/banjar
     → Body: { propertyId, contributionDate, contributionType, amount?, description? }
     → Create and return new row

DELETE /api/banjar/:id
     → Soft-delete or hard-delete — verify property ownership first
```

### Staff members

```
GET    /api/staff?propertyId=:id
       → Return all active staff for property

POST   /api/staff
       → Body: { propertyId, name, role?, startDate?, bpjsKesehatanStatus?, bpjsKetenagakerjaanStatus?, kitas?, kitasExpiry? }

PATCH  /api/staff/:id

## PART J — GLOSSARY TERMS ADDITIONS (`server/seed.ts`)

Add these 8 new terms. Seed is additive — do not modify existing 31 terms.

---

### 1. Banjar
- slug: `banjar`
- definition: The hyperlocal community governance unit in Bali — smaller than a village, typically covering a few hundred families. The banjar is administered by a Kelian Dinas and operates outside the formal government licensing system but holds significant informal authority.
- why: Banjar complaints can trigger inspections and operational interference even on a fully licensed property. Monthly contributions, ceremony participation, and staff registration with the banjar are considered essential practice for maintaining operational peace. New villa operators should formally introduce themselves to the Kelian Dinas before commencing operations.
- store: Introduction record and date, contribution log, ceremony records (Melaspas, Mecaru)
- pitfalls: Ignoring banjar relationship entirely; failing to notify banjar of building work or operational changes; not introducing new foreign operators to banjar head
- synonyms: ["community association", "village ward", "banjar adat", "Kelian Dinas"]
- tags: ["Community", "Local"]

### 2. Surat Keterangan Domisili (SKD)
- slug: `surat-keterangan-domisili`
- definition: A domicile letter issued by the local banjar confirming a company's or individual's registered address. Required for OSS registration, business address verification, and KITAS-related administrative processes.
- why: The address on the SKD must match the address on all other documents — NIB, NPWP, TDUP. Mismatches are the most common cause of OSS and OTA platform verification failures.
- steps: Attend banjar office with property documents, KITAS/passport → Banjar head interviews and issues SKD → Submit to kelurahan for official stamp → Valid for address-tied purposes
- store: SKD original or certified copy, issue date, renewal reminder
- pitfalls: SKD address not matching NIB/NPWP address; SKD expired (annual renewal); not updating SKD after address change
- synonyms: ["domicile letter", "address letter", "SKD", "surat domisili", "Letter of Domicile"]
- tags: ["Documents", "Local", "Corporate"]

### 3. PPAT (Notaris Tanah)
- slug: `ppat-notaris-tanah`
- definition: Pejabat Pembuat Akta Tanah — a special category of licensed notary specifically authorised to handle land transaction documentation in Indonesia. Different from a general notary.
- why: All land title transfers, HGB issuances, and notary title searches related to land must be handled by a PPAT. Using a general notary for land transactions is invalid. Verify PPAT accreditation before engaging.
- store: PPAT engagement letter, accreditation number, title search report, any land transaction deeds
- pitfalls: Using a general notary instead of a PPAT; not verifying PPAT accreditation; PPAT issuing clean title certificate without physical inspection of the land registry
- synonyms: ["land notary", "PPAT notary", "notary PPAT", "land deed official"]
- tags: ["Legal", "Documents", "Zoning"]

### 4. Hak Milik (SHM)
- slug: `hak-milik-shm`
- definition: Sertifikat Hak Milik — freehold title, the strongest form of land ownership in Indonesia. Available to Indonesian citizens only. Foreign nationals and foreign-owned companies (PT PMA) cannot hold Hak Milik. Any arrangement where a foreigner holds Hak Milik through a nominee Indonesian citizen is legally invalid and subject to forfeiture.
- why: Foreign operators must understand that Hak Milik is not available to them or their PT PMA. The correct title for PT PMA land is HGB. Nominee Hak Milik arrangements have been prosecuted — the foreigner has no legal recourse if the nominee claims the land.
- store: If purchasing/inheriting a villa: confirm title type. HGB certificate if correctly held. Legal opinion from PPAT.
- pitfalls: Purchasing a villa under a nominee Hak Milik arrangement; not converting Hak Milik to HGB before PT PMA takes ownership
- synonyms: ["freehold", "SHM", "freehold title", "full ownership", "Hak Milik freehold"]
- tags: ["Zoning", "Legal"]

### 5. Hak Pakai
- slug: `hak-pakai`
- definition: Right-to-Use title — available to foreign individuals holding a KITAS or KITAP for a single residential property with a minimum value of approximately IDR 5 billion. Cannot be used for commercial rental income. PT PMA entities use HGB, not Hak Pakai.
- why: Foreign operators sometimes believe Hak Pakai allows them to run a rental villa without a PT PMA. It does not — Hak Pakai is for personal residence only. Commercial rental income from a Hak Pakai property is not permitted and creates tax and immigration liability.
- store: Hak Pakai certificate, KITAS confirming eligibility, legal opinion
- pitfalls: Using Hak Pakai for commercial rental operations; not understanding the distinction between personal residential use and commercial hospitality
- synonyms: ["right to use", "right of use", "use title", "Hak Pakai certificate"]
- tags: ["Zoning", "Legal"]

### 6. PT PMDN
- slug: `pt-pmdn`
- definition: Perseroan Terbatas Penanaman Modal Dalam Negeri — a domestic limited liability company. In practice, the PT PMDN is increasingly the preferred operational entity for short-term villa rental licences in Bali, as local licensing authorities apply PT PMA restrictions to certain hospitality KBLI codes.
- why: Many villa operators are surprised to learn that PT PMA cannot always obtain short-term rental tourism licences under current local interpretation and enforcement. A PT PMDN with appropriate foreign investment structured correctly may be required as the operating entity. This distinction is critical before committing to a company structure.
- store: Akta Pendirian (domestic), SK Kemenkumham, NPWP, NIB under PT PMDN entity
- pitfalls: Assuming PT PMA is always the correct structure for villa operations; not verifying the licensing pathway for the specific KBLI before incorporating; conflating ownership structure with operational structure
- synonyms: ["domestic company", "Indonesian company", "PMDN entity", "local PT"]
- tags: ["Corporate", "Legal"]

### 7. PBB (Pajak Bumi dan Bangunan)
- slug: `pbb-pajak-bumi-bangunan`
- definition: Land and Building Tax — an annual local tax assessed on the ownership of land and buildings. Commercial properties pay at commercial rates, which are significantly higher than residential rates.
- why: Commercial villas paying PBB at residential rates are a common tax audit trigger. This gap is actively targeted by Bali tax authorities. The property must be registered at the correct commercial rate from the moment it begins commercial operations.
- steps: Confirm current PBB classification with local Bapenda → If residential, apply for reclassification to commercial → Pay annual PBB by the deadline (typically September in Bali) → Retain payment receipts
- store: PBB payment receipt (current year), classification confirmation, any reclassification correspondence
- pitfalls: Continuing to pay residential PBB after commencing commercial operations; missing the annual payment deadline; not updating PBB classification after renovations that increase property value
- synonyms: ["land tax", "building tax", "property tax", "pajak bumi", "PBB"]
- tags: ["Tax"]

### 8. THR (Tunjangan Hari Raya)
- slug: `thr-tunjangan-hari-raya`
- definition: The mandatory annual religious holiday bonus for all employees in Indonesia — equal to one month's salary. For Muslim employees: paid before Eid al-Fitr. For non-Muslim employees: paid before their primary religious holiday (Nyepi for Balinese Hindu, Christmas for Christian staff, etc.).
- why: THR is a legal obligation under Indonesian employment law, not a discretionary bonus. Late payment or non-payment constitutes an employment law violation and generates formal labour complaints. In the villa sector, THR disputes with housekeeper and maintenance staff are common and disruptive.
- steps: Calculate one month's gross salary per employee → Disburse at least 7 days before the relevant religious holiday → Obtain signed receipt from each employee → Report to Disnaker if required
- store: Disbursement records signed by each employee, payroll confirmation, any Disnaker reporting
- pitfalls: Not paying THR for part-time or fixed-term staff who qualify; paying after the holiday (still a violation even if paid late); not keeping signed receipts
- synonyms: ["holiday bonus", "religious bonus", "hari raya bonus", "THR allowance"]
- tags: ["Staff", "Employment"]
