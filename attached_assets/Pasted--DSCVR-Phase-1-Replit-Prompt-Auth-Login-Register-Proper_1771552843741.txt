### Step 3 — Auth API routes (`server/routes.ts`)

Add these routes **before** the existing `/api/terms` routes. Use `bcrypt` for password hashing (install if not present: `npm install bcrypt @types/bcrypt`).

**Middleware:**

```typescript
function requireAuth(req: Request, res: Response, next: NextFunction) {
  if (!req.session.userId) return res.status(401).json({ message: "Unauthorized" });
  next();
}
```

**Routes:**

`POST /api/auth/register`

- Body: `{ email: string, password: string }`
- Validate: email format, password min 8 chars
- Check email not already in use
- Hash password with `bcrypt.hash(password, 10)`
- Create user, set `req.session.userId = user.id`
- Return `{ id, email, isAdmin }` (never return password)

`POST /api/auth/login`

- Body: `{ email: string, password: string }`
- Find user by email, verify password with `bcrypt.compare`
- Update `lastLogin` timestamp
- Set `req.session.userId = user.id`
- Return `{ id, email, isAdmin }`

`POST /api/auth/logout`

- Destroy session
- Return `{ ok: true }`

`GET /api/auth/me`

- If session exists, return `{ id, email, isAdmin }`
- If not, return 401

**Properties routes (all require `requireAuth`):**

`GET /api/properties`

- Return all properties for `req.session.userId` where `isActive = true`

`POST /api/properties`

- Body: `{ propertyName, entityName, nib?, address?, regency?, kbli? }`
- Create property with `userId = req.session.userId`
- Return created property

`PATCH /api/properties/:id`

- Verify property belongs to `req.session.userId`
- Update fields, set `updatedAt`
- Return updated property

`DELETE /api/properties/:id`

- Verify ownership, set `isActive = false` (soft delete)
- Return `{ ok: true }`

### Step 6 — Frontend: Auth pages

#### `client/src/hooks/useAuth.ts`

```typescript
import { useQuery, useMutation, useQueryClient } from "@tanstack/react-query";
import { apiRequest } from "@/lib/queryClient";

interface AuthUser {
  id: string;
  email: string;
  isAdmin: boolean;
}

export function useAuth() {
  const queryClient = useQueryClient();

  const { data: user, isLoading } = useQuery<AuthUser | null>({
    queryKey: ["/api/auth/me"],
    queryFn: async () => {
      try {
        const res = await fetch("/api/auth/me");
        if (res.status === 401) return null;
        return res.json();
      } catch {
        return null;
      }
    },
    retry: false,
    staleTime: 5 * 60 * 1000,
  });

  const logoutMutation = useMutation({
    mutationFn: () => apiRequest("POST", "/api/auth/logout"),
    onSuccess: () => {
      queryClient.setQueryData(["/api/auth/me"], null);
      queryClient.invalidateQueries();
    },
  });

  return {
    user: user ?? null,
    isLoading,
    isAuthenticated: !!user,
    logout: logoutMutation.mutate,
  };
}
```

#### `client/src/components/protected-route.tsx`

```typescript
import { useAuth } from "@/hooks/useAuth";
import { Redirect } from "wouter";

export function ProtectedRoute({ children }: { children: React.ReactNode }) {
  const { isAuthenticated, isLoading } = useAuth();
  if (isLoading) return (
    <div className="min-h-screen flex items-center justify-center" style={{ background: "var(--app-bg)" }}>
      <div className="text-[#14B8A6] font-heading text-sm tracking-widest uppercase animate-pulse">Loading…</div>
    </div>
  );
  if (!isAuthenticated) return <Redirect to="/login" />;
  return <>{children}</>;
}
```

## CONSTRAINTS

1. **Match DSCVR design language exactly**: deep navy bg (#07101E), teal accent (#14B8A6), Montserrat headings, Lato body, CSS custom properties for theming
1. **Do not break any existing functionality** — the compliance flow, audit, guide tabs, glossary, and admin page must all continue to work unchanged
1. **Session secret**: add `SESSION_SECRET` to Replit Secrets panel. The code should work with a fallback dev value but log a warning if it’s missing
1. **Run `npm run db:push`** after all schema changes to sync the database
1. **bcrypt** — install if not already present: `npm install bcrypt @types/bcrypt`
1. **Error handling** — all API routes should return consistent `{ message: string }` error objects. Frontend shows these in the UI, never console.log only
1. **Passwords** — never return password hash from any API endpoint
