## What this implements

1. **Dual-theme system** — Light (white/red/IBM Plex, new default) and Dark (navy/teal/Montserrat, original). Persists to localStorage. Toggled from the topbar and a settings page switcher.
2. **Zero emoji rule** — No emoji anywhere on any page: landing, onboarding, free tier, pro tier, admin panel, emails, error pages. Every icon replaced with an inline SVG.

Both changes apply globally to: landing page, onboarding, free dashboard, pro dashboard, admin panel, settings, disclaimers, calendar, document vault, regulatory intelligence, alerts, all modals, all emails.

## PART 1 — THEME SYSTEM

### Step 1 — ThemeContext

Create `/src/contexts/ThemeContext.tsx`:

```tsx
import { createContext, useContext, useState, useEffect, ReactNode } from 'react';
import { applyTheme, ThemeName } from '../lib/themeTokens';

interface ThemeContextValue {
  theme: ThemeName;
  setTheme: (t: ThemeName) => void;
  toggleTheme: () => void;
}

const ThemeContext = createContext<ThemeContextValue>({
  theme: 'light', setTheme: () => {}, toggleTheme: () => {},
});

export function ThemeProvider({ children }: { children: ReactNode }) {
  const [theme, setThemeState] = useState<ThemeName>(() => {
    try {
      const s = localStorage.getItem('dscvr-theme') as ThemeName;
      return s === 'light' || s === 'dark' ? s : 'light';
    } catch { return 'light'; }
  });

  useEffect(() => {
    applyTheme(theme);
    try { localStorage.setItem('dscvr-theme', theme); } catch {}
  }, [theme]);

  const setTheme = (t: ThemeName) => setThemeState(t);
  const toggleTheme = () => setThemeState(p => p === 'light' ? 'dark' : 'light');

  return (
    <ThemeContext.Provider value={{ theme, setTheme, toggleTheme }}>
      {children}
    </ThemeContext.Provider>
  );
}

export const useTheme = () => useContext(ThemeContext);
```

};

export function applyTheme(theme: ThemeName): void {
  const tokens = themeTokens[theme];
  const root = document.documentElement;
  Object.entries(tokens).forEach(([k, v]) => root.style.setProperty(k, v));
  root.setAttribute('data-theme', theme);
  let link = document.getElementById('dscvr-font-link') as HTMLLinkElement | null;
  if (!link) {
    link = document.createElement('link');
    link.id = 'dscvr-font-link';
    link.rel = 'stylesheet';
    document.head.appendChild(link);
  }
  link.href = themeFontUrls[theme];
}

### Step 3 — Prevent flash of wrong theme

Add this as the **first** `<script>` in `index.html` before anything else:

```html
<script>
  try {
    const t = localStorage.getItem('dscvr-theme') || 'light';
    document.documentElement.setAttribute('data-theme', t);
    if (t === 'dark') {
      const r = document.documentElement;
      r.style.setProperty('--bg', '#07101E');
      r.style.setProperty('--surface', '#0C1A2E');
      r.style.setProperty('--txt', '#F1F5F9');
    }
  } catch(e) {}
</script>
```

## PART 2 — ZERO EMOJI RULE

### The rule

**No emoji anywhere on any page.** This covers:
- Landing page, pricing page, onboarding flow
- Free tier dashboard and all its tabs
- Pro tier dashboard and all its tabs
- Admin panel
- Settings page
- Emails (transactional + marketing)
- Error pages (404, 500, maintenance)
- Empty states, tooltips, toasts, modals
- Mobile views
- Any text string passed as a prop, label, title, or description

### What replaces emoji

Every icon must be an **inline SVG** — no emoji, no icon font, no external image for icons. Use the `<Icon>` component below.

### Step 2 — Audit and replace every emoji occurrence

Search the entire codebase for emoji using this regex in your IDE or Replit's search:

```
[\u{1F300}-\u{1F9FF}\u{1FA00}-\u{1FFFF}\u{2600}-\u{26FF}\u{2700}-\u{27BF}]
```

Enable the `u` flag (Unicode mode). Replace every match with the appropriate `<Icons.X />` component from the library above.

Also search for these specific Unicode characters that are not emoji but must also be replaced:
```
⬡  □  ◻  ◎  ◈  ◯  ⚠  ⚖  ▣  ☀  ✦  ②  ＋  ♻
```

Replace each with its corresponding `<Icons.X />` component.

### Step 4 — Text strings in JS/TS

Emoji in JavaScript string values (e.g. event data, labels, config objects) must also be replaced:

```ts
// Wrong
const eventTypes = { tax: '💰', safety: '🛡', ops: '📋' };

// Right — use SVG string or component reference
const eventTypes = { tax: 'tax', safety: 'safety', ops: 'ops' };
// Then render: <Icons.file /> based on the type string
```

For event data objects where icon is stored as a string and rendered as innerHTML, use SVG string values:
```ts
// Store SVG as string constant
const SVG_SHIELD = '<svg width="14" height="14" viewBox="0 0 14 14" fill="none" stroke="currentColor" stroke-width="1.3" stroke-linecap="round"><path d="M7 1L2 3.5v4c0 3.5 2.5 5.5 5 6 2.5-.5 5-2.5 5-6v-4L7 1z"/></svg>';

// Use in data
{ id: 'insurance', icon: SVG_SHIELD, title: 'Insurance Renewal' }
```
